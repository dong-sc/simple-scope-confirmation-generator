# Product Brief

## 中文名稱

服務範圍確認單製作工具

## English Name

Simple Scope Confirmation Generator

## Repo Name

simple-scope-confirmation-generator

## Core Idea

A simple no-login service scope confirmation generator for freelancers and small studios.

It helps users clarify included services, excluded services, deliverables, revision rules, client-provided materials, timeline notes, and communication boundaries before project work begins.

It is not a contract generator.

It is not a legal document system.

It is not a project management platform.

## Target Users

- freelancers
- small studios
- solo service providers
- designers
- photographers
- editors
- consultants
- lecturers
- anyone who needs to confirm project scope before starting work

## Main Use Case

A user is about to start a project and wants to clarify the work scope with a client.

They open the tool, fill in familiar fields, preview a clean scope confirmation document, and print, save as PDF, or copy a plain-text confirmation message.

## Key Features

- project and confirmation information
- provider and client information
- project goal and collaboration focus
- included service scope list
- excluded service scope list
- deliverable list
- revision and change request rules
- client materials checklist
- timeline and payment reminder text
- notes and confirmation text
- copy plain text
- print / save as PDF
- localStorage draft persistence

## Legal Boundary

The generated content is only for communication and project scope confirmation.
It is not a legal contract.
It is not legal advice.
Users should consult a qualified professional if they need formal legal documents.

## Success Criteria

A first-time user should be able to create a usable scope confirmation document within 3 minutes.

The tool should not require login, explanation, backend setup, or cloud storage.
